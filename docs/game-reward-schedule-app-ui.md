# 游戏奖励式日程计划 APP 交互式 UI 稿设计

## 1. 设计目标与原则
- **激励感**：突出完成任务后的成就感，以明亮渐变、动效和金币反馈强化奖励体验。
- **清晰可操作**：日程操作流程需一眼可见，核心操作（创建任务、标记完成、查看奖励）保持 1-2 次点击内完成。
- **轻量化沉浸**：通过柔和色彩与留白缓解日程压力，避免过度游戏化造成信息噪音。
- **模块化扩展**：UI 组件采用设计令牌与组件库规范，方便后续扩展排行榜、AI 助手等功能。

## 2. 设计风格基调
- **品牌色系**：
  - 主色 `#5D5FEF`（勇气紫蓝）：用于按钮、激励状态条，传递坚持感。
  - 辅色 `#FFB547`（金币琥珀）：用于奖励数据、徽章与动态提示。
  - 提示色 `#32C5FF`（清新蓝）：用于提醒、链接和次级高亮。
  - 成功色 `#4CD964`、警告色 `#FF6B6B`，与系统提示保持一致。
- **中性色**：背景 `#F5F7FB`，卡片 `#FFFFFF`，正文 `#1E2233`，次级文字 `#6B7384`。
- **字体**：安卓系统默认（思源黑体/Roboto）。标题使用中粗（Medium），正文 Regular。
- **图标与插画**：圆角、线性+面性结合，金币与火焰等强化激励语境。

## 3. 设计令牌 (Design Tokens)
| 类别 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| 颜色 | `color.primary` | #5D5FEF | 主按钮、页签激活 |
| 颜色 | `color.reward` | #FFB547 | 金币、徽章、奖励数据 |
| 颜色 | `color.background` | #F5F7FB | 应用背景 |
| 颜色 | `color.surface` | #FFFFFF | 卡片与浮层背景 |
| 颜色 | `color.text.primary` | #1E2233 | 正文文字 |
| 颜色 | `color.text.secondary` | #6B7384 | 次要文字 |
| 字体 | `font.title` | 20sp, Medium | 一级标题 |
| 字体 | `font.body` | 14sp, Regular | 正文 |
| 圆角 | `radius.card` | 16dp | 卡片边角 |
| 阴影 | `shadow.card` | 0 8 20 rgba(18, 21, 52, 0.06) | 卡片悬浮 |
| 动效 | `motion.fast` | 120ms ease-out | 按钮反馈 |
| 动效 | `motion.medium` | 240ms ease-in-out | 卡片展开、底部弹层 |

## 4. 信息架构与导航
- **底部导航栏**（4 个 Tab）：
  1. 今日日程（Home）
  2. 奖励中心（Rewards）
  3. 成长统计（Insights）
  4. 个人中心（Profile）
- **全局浮动操作按钮**：位于首页右下角，点击打开任务创建弹层。
- **全局状态条**：顶部状态条展示当日金币、连续完成天数，支持点击跳转到奖励中心。
- **交互模式**：底部导航用于页面切换；页面内采用卡片分组、水平标签（Segmented Control）切换不同列表视图。

## 5. 核心页面交互稿

### 5.1 新手引导 & 登录
1. **引导页**（3 屏横向滑动）：
   - 屏 1："完成计划，积累金币"，插画为用户打勾任务。
   - 屏 2："攒够金币，奖励自己喜欢的物品"，展示兑换礼盒。
   - 屏 3："连续完成挑战，解锁专属勋章"。
   - 底部进度指示器 + "立即开始" CTA。
2. **登录页**：
   - 顶部 Logo + Slogan。
   - 中部手机号/邮箱输入框 + 验证码按钮。
   - 底部："还没有账号？注册" 文本按钮。
   - 提供三方登录图标区域，点击触发弹层说明。
   - 验证码按钮点击后 60s 倒计时，禁用状态颜色 `color.text.secondary`。

### 5.2 今日日程（首页）
- **布局**：
  - 顶部状态条卡片：显示今日日期、累计金币、连续完成天数，点击卡片翻转展示兑换目标进度。
  - 中部 Segmented Control："全部任务"/"高优先级"/"已完成"。
  - 任务列表：卡片包含任务标题、时间段、奖励金币、难度标签。
  - 右上角筛选图标，点击弹出底部筛选面板（优先级、时间段、标签）。
- **交互细节**：
  - 卡片左滑露出快捷操作：完成、延后、删除。
  - 点击卡片打开任务详情底部弹层，展示描述、提醒、奖励算法拆解。
  - 完成任务按钮包含金币飘落动效（240ms），完成后卡片缩放→淡出至“已完成”列表。
  - 如果任务带提醒，时间到达时推送顶栏提醒，点击可直接跳转详情弹层。

### 5.3 创建/编辑任务
- **入口**：悬浮按钮或任务详情的“编辑”按钮。
- **形式**：底部全屏弹层，分段式表单。
  1. 标题 + 描述输入。
  2. 时间选择（开始/结束），支持快捷选择（上午/下午/晚上）。
  3. 重复规则（无、每日、工作日、自定义周几）。
  4. 优先级与难度滑杆（3 档），展示预计奖励金币预览。
  5. 提醒设置（开关、提醒时间、提醒方式）。
- **交互细节**：
  - 表单滚动到顶部时，保存按钮固定于底部，状态根据表单校验启用或禁用。
  - 编辑时展示最近一次完成记录和 streak 信息，帮助用户调整。

### 5.4 奖励中心
- **顶部头图**：展示当前金币余额、目标物品卡片（名称、目标金额、进度条、预计达成日期）。
- **区块一：金币流水**
  - 列表按日期分组，卡片显示来源任务/签到、获得/消耗金币数量。
  - 点击记录展示详情弹层，包含奖励计算公式拆解。
- **区块二：兑换目标**
  - 横向卡片滑动，展示已设定的现实物品目标。
  - 点击卡片进入目标详情页，可记录“已兑换”并上传凭证照片。
- **区块三：签到与 streak**
  - 每日签到九宫格；点击签到按钮触发金币爆炸粒子动效。
  - 连续签到天数达到阈值时，顶部出现“解锁连签礼包”横幅，点击跳转任务弹层。

### 5.5 成长统计
- **顶部时间筛选**：日/周/月切换。
- **卡片布局**：
  1. 完成率折线图（高亮 streak 峰值）。
  2. 任务类别分布环形图。
  3. 金币收入 vs 支出柱状图。
  4. 成就墙：勋章网格，灰阶代表未解锁，点击显示解锁条件。
- **交互细节**：图表支持点击数据点显示 tooltip；支持左右滑动切换不同数据卡片。

### 5.6 个人中心
- **信息头部**：头像、昵称、等级徽章、连续完成天数。
- **设置列表**：账号安全、通知偏好、奖励规则说明、反馈与帮助。
- **实验室入口**：展示“AI 日程建议”等待上线功能，点击可报名内测。
- **颜色主题切换**：切换浅色/深色，预览卡片展示实时变化。

## 6. 组件库规范
- **按钮**：
  - 主按钮（Filled）：背景 `color.primary`，文字白色，禁用态 40% 透明。
  - 次按钮（Outlined）：边框 `color.primary`，文字 `color.primary`，按下态填充 12% 透明主色。
  - 图标按钮：圆形 48dp，阴影 `shadow.card`。
- **卡片**：
  - 标准卡片：圆角 16dp，阴影 `shadow.card`，内部使用 16dp 间距。
  - 可滑动卡片：支持左滑露出 3 个操作按钮，按钮按照完成（绿色）、延后（蓝色）、删除（红色）。
- **标签/Chip**：难度标签使用渐变背景（浅紫→深紫），奖励标签使用 `color.reward`。
- **底部弹层**：顶部圆角 28dp，拖动条指示；背景半透明遮罩 `rgba(30,34,51,0.4)`。
- **空状态**：插画 + 文案，按钮引导创建任务或设置目标。

## 7. 交互流程说明
1. **完成任务 → 获取奖励 → 查看金币**：
   - 用户在首页滑动完成任务 → 动效反馈 → 顶部状态条金币数增加 → 自动弹出“奖励已到账”轻提示。
   - 用户点击提示 → 跳转奖励中心 → 高亮最新一条金币流水。
2. **金币达成目标提醒**：
   - 当金币余额 ≥ 目标金额 90% 时，在首页状态条显示提醒按钮 → 点击弹出目标详情弹层。
   - 用户可记录期望购买时间或标记“已兑换”。
3. **签到 streak 断档补救**：
   - 若当天 20:00 前未签到，发送提醒 Banner → 点击跳转签到卡片。
   - streak 断档后出现“补签卡”引导，点击后弹出购买补签卡（使用金币）的确认弹层。
4. **AI 建议任务（预留）**：
   - 首页顶部卡片显示“AI 推荐”标签 → 点击进入半屏弹层，展示建议任务，用户可一键添加或忽略。

## 8. 原型链接与交付建议
- **原型工具**：建议使用 Figma，采用 Auto Layout + Component + Variant 管理状态。
- **原型结构**：
  - `Page 1`: Flow - Onboarding & Auth
  - `Page 2`: Flow - Daily Schedule & Task Detail
  - `Page 3`: Flow - Rewards & Redemption
  - `Page 4`: Flow - Insights & Profile
- **交互设置**：
  - 使用 `Smart Animate` 实现任务完成动效与卡片翻转。
  - 原型内设置 Anchor Links 实现页面内跳转（如顶部状态条 → 奖励中心）。
  - 添加 `Overlay` 组件模拟底部弹层。
- **交付物**：提供 Figma 原型链接、导出的 PNG 预览、设计令牌 JSON（供前端/主题系统使用）。

## 9. 可用性测试建议
- 进行 5-8 位目标用户的可用性测试，重点观察：
  1. 是否理解金币与现实奖励之间的关系。
  2. 任务完成后的反馈是否足够激励。
  3. 奖励中心的兑换目标设置流程是否顺畅。
- 根据反馈迭代任务完成动效强度、奖励提示频率和数据可视化表达。
